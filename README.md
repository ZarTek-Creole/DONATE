## Projets

Voici quelques dépôts publics, et [l'ensemble de mes projets](https://github.com/ZarTek-Creole?tab=repositories).

### IRC et Eggdrop

- [mirc-znc-interface](https://github.com/ZarTek-Creole/mirc-znc-interface) : script mIRC pour gérer un bouncer ZNC (menu, journal des commandes, réseaux IRC).
- [TCL-Youtube-Link](https://github.com/ZarTek-Creole/TCL-Youtube-Link) : script Eggdrop qui récupère les informations d'une vidéo via l'API YouTube v3.
- [TCL-EvaServ](https://github.com/ZarTek-Creole/TCL-EvaServ) : services IRC « Eva » en TCL/Eggdrop.
- [EggNet-Docker](https://github.com/ZarTek-Creole/EggNet-Docker) : image Docker pour lancer plusieurs Eggdrops en botnet de façon automatisée.
- [TCL-DictionaryAPI](https://github.com/ZarTek-Creole/TCL-DictionaryAPI) : script Eggdrop qui interroge l'API Dictionary v2 pour les définitions.
- [TCL-SCRIPT-MANAGER](https://github.com/ZarTek-Creole/TCL-SCRIPT-MANAGER) : gestionnaire de scripts TCL en terminal, avec des listes sources, un peu comme un APT pour Eggdrop.
- [docker-znc](https://github.com/ZarTek-Creole/docker-znc) : ZNC sous Docker.

### Linux, Docker et réseaux

- [WireGuard-MTU-Optimizer](https://github.com/ZarTek-Creole/WireGuard-MTU-Optimizer) : script qui teste et recommande un MTU pour une interface WireGuard.
- [plexmediaserver_updater](https://github.com/ZarTek-Creole/plexmediaserver_updater) : mise à jour automatisée de Plex Media Server sous Linux.
